# RouterPilot v2.4.4

RouterPilot v2.4.4 is a maintenance and usability release focused on VPN routing visibility, Router Logs, and traffic presentation.

## VPN

- View devices assigned to client-specific VPN routing, with assignment kept separate from available device-presence status.
- VPN Client and Tailscale now have dedicated internal tabs under VPN.
- Overview continues to distinguish client-specific VPN routing from the router's default Internet route.

## Router Logs

- Router Logs is now available as a dedicated tab within Router.
- The bounded recent list retains the newest 100 entries.
- Improved search and filter presentation in light and dark themes.
- Selected event details appear above the list and remain stable when longer messages wrap.
- Improved row-selection presentation and spacing beside the scrollbar.

## Traffic presentation

- Recent traffic samples now use the same readable KiB/s and MiB/s formatting as RouterPilot's main traffic figures.

- Windows 10 build 19041 or later, or Windows 11
- Supported GL.iNet router
- SSH access for router functionality that requires it
- AdGuard Home for AdGuard-specific features
