# RouterPilot v2.4.5

## ✨ Highlights

- Native GL.iNet Smart Queue Management controls are now available in **Router → SQM** when the router exposes the native SQM API. Changes are staged, validated and verified by an authoritative read-back.
- Router firmware information, update checks and lifecycle tools now live in **Router → Firmware**.
- Client Details now presents clearer device and connection context, including client-specific VPN routing status where available.
- RouterPilot can now use dedicated AdGuard Home credentials when they differ from the router login; using router credentials remains the default.

## 🛠 Improvements

- Improved the SQM queue-rule control and Router navigation layout.
- Removed the redundant Recent router events card from Router Overview. Router → Logs remains the dedicated log viewer.
- Improved the Light and Dark Mode presentation of the AdGuard Home blocklist editor.
- Refined the About support area, including PayPal alongside GitHub Sponsors and Buy Me a Coffee.
